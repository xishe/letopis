# Летопись — кликабельный прототип

Светлое SPA в стиле Linear: инженер один раз фиксирует результат, а из записей собираются self-review, отчёты команд и план-факт. Бэкенда нет: данные демо (инженер «Иван Петров», backend, апр–сен 2026) лежат в `src/data/demo.json`, состояние хранится в памяти и `localStorage`.

Стек: Vite, React 18, TypeScript, Tailwind CSS, react-router 6, zustand, framer-motion, lucide-react, vitest.

## Запуск

```bash
npm install
npm run dev      # локальный сервер разработки
npm test         # тесты (vitest)
npm run build    # проверка типов и сборка в dist/
npm run preview  # просмотр собранной версии
```

## Демо-путь для питча (≈2,5 минуты)

1. **Лендинг `/`**: заголовок, живое превью интерфейса, тезисы исследования («Опрос 5 инженеров, 2026»). Кнопка «Открыть демо».
2. **Подключение источников**: подключить Jira, GitLab, Confluence, Контур.Толк, выбрать период, нажать «Собрать хронику».
3. **Хроника**: сверху находки автосбора. Подтвердить одну, добавить эффект к карточке «нет цифры». Горячие клавиши: `C`, `J/K`, `Ctrl+K`.
4. **Карточка результата**: источники, подтверждения, переключатель «Видит руководитель».
5. **Сборка self-review**: выбрать шаблон и результаты, «Собрать черновик».
6. **Черновик**: потоковая печать, сноски `[R-1]`, чек-лист готовности, «Отправить руководителю», «Скачать .md».
7. **Команда `/app/team`**: результаты, которыми поделились авторы (показать пустое состояние, затем включить «Видит руководитель»).

Кнопка «Сбросить демо» в сайдбаре возвращает исходное состояние.

## Деплой на Netlify

Репозиторий подключается из папки `web/` (Base directory: `web`). Настройки лежат в `netlify.toml`: команда `npm run build`, публикация `dist`, правило SPA-редиректа `/* → /index.html (200)`, поэтому прямые ссылки вида `/app/chronicle` работают. Альтернатива: собрать локально и загрузить папку `dist` через Netlify Drop.

Сайт: https://letopis.netlify.app. Репозиторий `xishe/letopis` привязан к проекту `letopis`, каждый push в `main`, который меняет что-то в `web/`, запускает сборку и публикацию автоматически (коммиты без изменений в `web/` Netlify пропускает).

## Структура

```
public/            favicon.svg, og.svg, og.png (картинка для ссылки, 1200×630)
src/
  app/             оболочка приложения и сайдбар
  brand/           логотип
  data/            demo.json и типизированные экспорты
  store/           zustand-стор демо-состояния
  ui/              свои примитивы: Button, Chip, StatusDot, EffectPill, SidePanel, Modal, Toast
  features/
    landing/       лендинг
    onboarding/    подключение источников
    chronicle/     хроника и карточка результата
    reports/       сборка и черновик self-review
    team/          результаты команды
  routes.tsx       маршруты
netlify.toml       сборка и редирект для SPA
```

Учебный проект ИТМО, 2026. Цифры на лендинге взяты из опроса 5 инженеров и не являются обещанием экономии.
