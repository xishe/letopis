# Летопись

Учебный проект (ИТМО, курс ОПП, 2026). B2B-сервис для инженерных команд: результаты работы и подтверждения фиксируются по ходу периода, а из записей собираются self-review, отчёты команд и план-факт по инициативам.

**Демо:** https://letopis.netlify.app

## Что в репозитории

| Папка | Что это |
|-------|---------|
| [`web/`](web/) | Основной прототип: SPA в стиле Linear (Vite, React, TypeScript, Tailwind). Демо-путь от подключения источников до готового self-review. Деплоится на Netlify. |
| `letopis/`, `app.py`, `tests/` | Первый прототип на Streamlit: импорт CSV из Jira и GitLab → группировка в результаты → черновик со ссылками. Из него собираются демо-данные для `web/`. |
| `data/` | Генератор и демо-выгрузки Jira и GitLab (вымышленный инженер, апр–сен 2026). |
| `docs/superpowers/` | Дизайн-спека и план реализации. |

## Быстрый старт

```bash
cd web
npm install
npm run dev
```

Тесты: `npm test` в `web/`, `python -m unittest discover -s tests -t .` в корне.
